# Sirajudheen T K — Portfolio

A responsive, static portfolio website built with plain HTML, CSS and JavaScript.

## Run locally

### Option 1 — VS Code + Live Server
1. Install VS Code.
2. Open this folder.
3. Install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.

### Option 2 — No extension
Open `index.html` directly in your browser. Most of the site will work, but Live Server is recommended for development.

## Before publishing

1. Put your latest resume PDF in this folder and name it `resume.pdf`.
2. Replace the LinkedIn and GitHub placeholder URLs in `index.html`.
3. Review job dates and project descriptions against your latest resume.
4. Optionally replace the CSS-generated phone mockup with real project screenshots.
5. Test on mobile and desktop.

## Publish free

The site is static, so it can be hosted free on GitHub Pages, Cloudflare Pages, Netlify, or similar services.
